Голосовой Джарвис на телефоне

Браузер включает микрофон только на защищённом адресе (https). Для этого один раз поставьте на телефон сертификат нашего сервера.

1. Скачать сертификат

iPhone / iPad

  1. Откройте эту страницу в Safari и нажмите «Скачать сертификат» → «Разрешить».
  2. Настройки → Профиль загружен → Установить (введите код телефона).
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите «Proekt V2 local CA».

Android

  1. Нажмите «Скачать сертификат».
  2. Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС → выберите скачанный файл.
  3. Название пунктов зависит от телефона: можно найти в настройках поиском «сертификат».
2. Открыть сайт по https

Без сертификата сайт работает как раньше по обычному адресу — только без голоса. Сертификат действует только для нашего сервера в этой сети.

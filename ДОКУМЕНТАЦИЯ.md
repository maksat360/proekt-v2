# Проект V2 — портал швейного цеха SHARQ

Один сайт для всего цикла: цех шьёт → склад принимает и хранит → товар уходит на Wildberries, в магазин или сотрудникам.
Работает с компьютера и телефона, у каждого сотрудника свои права.

## Разделы

| Раздел | Что делает |
|---|---|
| **Цех** (`/static/cex/`) | заказы, партии, этапы пошива по маршруту, карточки кроя, сдельная зарплата, себестоимость, сотрудники и роли, выгрузка логинов в Excel |
| **Склад** (`#/wh`) | остатки, приход по партиям, адресное хранение, поставки (ЖСК, ККМ, Алтын, заказы сотрудников, FBO), журнал, выгрузка всего склада в Excel |
| **Заказы WB** | FBS-заказы по кабинетам Wildberries: подтверждение, сборка, поставки |
| **Магазин** | витрина с фото WB, карточка товара, правка названия, описания, фото и цен, корзина |
| **Продажи, Мои заказы** | продажи и личные заказы сотрудников |
| **Джарвис** | голосовой помощник; отвечает по правам сотрудника, окно открывается только кнопкой |

## Как устроено

```
Телефон / компьютер ──► server.py (порт 8787) ──► PostgreSQL «portal»   ← источник истины
                                    │                └─ товары, приход, размещения, отгрузки,
                                    │                   заказы, адреса, контрагенты, журнал
                                    ├─► Excel-книга цеха на Google Диске (справочник товаров, листы цеха)
                                    └─► Wildberries API (заказы FBS, фото, остатки)
```

- **Остаток** = приход − отгрузки (в PostgreSQL). Excel для остатка больше не используется.
- **Приход** сразу попадает в остаток («сразу на склад»), адрес необязателен.
- **Адрес** — надстройка: показывает, *где* лежит товар, на сам остаток не влияет.
- **Все изменения на сервере** идут по одному, без гонок (общая блокировка записи).

## Адресное хранение

| Код | Что это |
|---|---|
| `P1-3-05` | ячейка **внутри**: стеллаж 1, этаж 3, ячейка 5. Открытый товар, отсюда собирают |
| `N-3-17` | ячейка **снаружи**: этаж 3, ячейка 17. Здесь стоят коробки |
| `K-0001` | **коробка**: всегда стоит в ячейке N, переезжает целиком |
| `M-0001` | **мешок**: без адреса, из него берут частями |

**Сканер:**
- коробка → ячейка N — коробку переставили;
- коробка → ячейка P — коробку вскрыли, весь товар ушёл в ячейку;
- мешок → «сколько взял» → ячейка — товар переложили;
- место → товар → количество — товар положили.

Коды коробок и мешков выдаются только новые. Если потеряли этикетку: старый код вручную → новая этикетка, и товар переходит на новый код.
Буквы в кодах латинские; сканер в русской раскладке понимается сам.

Сейчас: 180 ячеек внутри (P1–P6), 196 снаружи (N), коробки K-0001…0050, мешки M-0001…0010.

## Роли (основные)

Администратор, Менеджер, Технолог, Складчик, Закройщик, Упаковщик, Конструктор, Снабженец, Бухгалтер, Клиент.
Складские роли: Приёмщик, Сборщик, Комплектовщик. Права каждой роли и каждого сотрудника настраиваются в «Сотрудники и роли».

## Где работает и как попасть

- **Сервер** — этот MacBook. Портал запускается сам при входе в Mac и поднимается сам, если упал (служба `kg.sharq.portal`).
- **В интернете:** https://temp-macbookpro.tail5de778.ts.net (Tailscale Funnel, бесплатно).
- **В сети цеха:** `http://<адрес-Mac>:8787`.
- **Mac не должен спать.** Автосон выключен, но **крышку не закрывать**: с закрытой крышкой Mac засыпает, и сайт недоступен.

Перезапуск портала после изменений кода:
```bash
launchctl kickstart -k gui/$(id -u)/kg.sharq.portal
```
Журнал сервера: `/tmp/portal.log`.

## Резервные копии

| Что | Куда | Когда |
|---|---|---|
| Код | GitHub, приватный репозиторий `maksat360/proekt-v2` | после каждого «закоммить и отправь» |
| База + папка `data/` | Google Диск → «Мой диск/Резерв портала» | каждый день в 03:00, хранятся 30 дней |
| База (локально) | `data/sql/backups/` | при каждой копии и перед крупными изменениями |

Восстановить базу: `gunzip -c портал_ДАТА.sql.gz | psql portal`.
В архиве `данные_…` лежат токены WB и хеши паролей — доступ к папке никому не давать.
